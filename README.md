# 生活光影 · Yu-zi-fei 的照片博客

用照片和文字，记录生活里值得留住的片段。

这是一座彩色手账风格的个人博客：照片、日记和语录按照时间排列，也可以通过标签筛选。页面支持浅色与深色模式，点击卡片可以查看照片大图或阅读完整文字。

## 浏览博客

打开 `scrapbook-note.html` 即可浏览。照片通过 `entries.js` 中的网络地址加载，浏览时需要能够访问这些图片地址。

## 更新内容

博客的照片、日记、语录和标签都写在同一文件夹的 `entries.js` 中。文件开头有添加记录的示例和说明。

- **照片**：填写图片地址、日期和标签，也可以附上一段文字。
- **日记**：使用反引号包住正文，直接按回车换行，空一行即可分段。
- **语录**：用文字记录喜欢的句子。

每条记录需要一个不重复的 `id`。添加或修改内容后，保存文件并刷新页面即可看到变化。

> 本文件夹里的 `entries.js` 是独立副本。修改它会影响本文件夹中的博客页面，不会自动同步到其他文件夹里的副本。
